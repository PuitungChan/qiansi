# 《牵丝》画面视觉规范 v1.0

> 配套原型图：`prototype/scene_broken_bridge.png`
> 可编辑源文件：`prototype/scene_broken_bridge.html`
> 场景：第一章 · 断桥 —— 玩家刚断丝，石块在弹道上飞向墨甲

---

## 1. 一句话视觉主张

**一张会动的宣纸，上面只有一条金线。**

画面的一切都是淡的、虚的、留白的。只有灵丝是高饱和的、锐利的、有声音的。玩家的注意力永远只能落在一个地方——**丝**。

## 2. 色彩系统

### 2.1 铁律

> **除灵丝外，画面中所有元素的饱和度不超过 15%。**

这条铁律适用于场景、角色、敌人、特效、UI、宣传图、商店图、图标。任何一次例外都要有明确的玩法理由。

### 2.3 为什么敌人比主角黑

主角是**墨色剪影**（`#3A3830`），无相是**浓墨**（`#0B0B08`）。

这不是美术偏好，是可读性设计：玩家在任何一帧都必须能瞬间分清"哪是我、哪是敌人"。当敌人是纯黑而主角是深灰时，即使两者重叠也能读出来。

## 3. 画面层次（自后向前）

原型图严格按此顺序绘制，共 9 层：

| # | 层次 | 内容 | 处理 |
|---|---|---|---|
| 1 | 纸 | 径向渐变 + 颗粒 | 中心亮、四角沉 |
| 2 | 月 | 淡白圆盘 | 只做留白的参照物，不给细节 |
| 3 | 远山 | 4 层脊线 | 越远越淡越糊；高斯模糊 22→4px 递减 |
| 4 | 雾 | 纸色椭圆 | **用纸色而不是白色**，否则会发灰 |
| 5 | 断桥主体 | 实心墨块 + 笔触质感 | 见 §4.2 |
| 6 | 梁柱 / 铁链 | 实心 + 纹理 | |
| 7 | 无相 | 墨体 + 溅墨 | 见 §5.3 |
| 8 | 弹道 / 石块 | 淡墨掠痕 + 金点虚线 | |
| 9 | 主角 / 灵丝 | 剪影 + 金线 | 灵丝永远在最上层之一 |
| 10 | HUD / 命名 | 金色 + 墨色 | |

**注意第 4 层。** 雾气如果用纯白 `#FFFFFF`，在暖色纸面上会形成冷灰色带，画面立刻变脏。必须用纸色系（`#F7F1E2`）。

## 4. 墨的质感：技术做法

这是整个视觉的关键，也是最容易做砸的地方。

### 4.1 核心认知

**平面多边形永远画不出墨。** 一块纯色填充的矩形就是一块板砖，无论加多少噪点。

真正的墨是三层叠加的结果：
1. **实心墨块**——提供质量
2. **边缘位移**——提供毛糙的轮廓
3. **叠笔**——提供浓淡变化

原型图的实现：实心路径 + `feTurbulence` + `feDisplacementMap`，再叠 14–18 道半透明笔触。

### 4.2 结构物（桥、柱、建筑）配方

```
① 画一个不规则实心路径（有起伏的上下沿）
     ↓ 施加 wet 滤镜
② feTurbulence baseFrequency="0.008 0.021" numOctaves=5
   feDisplacementMap scale=11
     ↓ 得到毛糙的墨块轮廓
③ 叠 14–18 道笔触（stroke-width 1.6–9，opacity 0.10–0.34）
   颜色在 #5A564A（提亮）与 #0F0D0A（压暗）之间随机
     ↓ 施加 dry 滤镜
④ feTurbulence baseFrequency="0.05 0.11"，scale=5 → 飞白
     ↓
⑤ 在断口/转折处补一道重墨（#100E0B, opacity 0.4–0.55）
```

**两个滤镜分工明确：**
- `wet`（低频，scale 11）= **湿笔**，用于大形轮廓，边缘像墨在纸上洇开
- `dry`（高频，scale 5）= **干笔**，用于纹理，产生飞白

### 4.3 绝对不要做的事

| ❌ 错误 | ✅ 正确 |
|---|---|
| 用一个矩形画桥面 | 不规则路径 + 位移 + 叠笔 |
| 用很多细笔叠出实体 | 先实心，再叠笔 |
| 用纯黑画所有墨 | 分 `#0B0B08`（无相）/ `#26241D`（结构）/ `#3A3830`（主角） |
| 用白色画雾 | 用纸色 |
| 高斯模糊超过 25px 画薄形状 | 模糊会把薄形状的 alpha 稀释到看不见——形状必须先够厚 |

（最后一条是原型制作中真实踩过的坑：远山一开始填充高度只有 74px，配 44px 模糊后完全消失。）

## 5. 画面元素规范

### 5.1 主角 · 牵丝人

- **高度**：约 145px（1080p 下），占画面高 13%
- **颜色**：`#3A3830`，**不使用纯黑**
- **必须可读的三个部件**：头（含发髻）、束腰、伸出的前臂
- 颈部和躯干之间**留一道浅色缝隙**，否则头和身体会糊成一团
- 衣摆用 2 道提亮飞白（`#77725F` @ 25%）表现布料
- 指尖有一点金色高光（`r=5`，带 glow），是灵丝的起点

**姿态原则**：牵丝人永远是**收势**而不是**攻势**。她从不"打"，她只是"放"。

### 5.2 灵丝

**画面中唯一的高饱和元素。**

| 构成 | 参数 |
|---|---|
| 辉光层 | 同路径，stroke-width 9，opacity 0.30，glow 滤镜 |
| 丝身 | 渐变描边（暗金→亮金），stroke-width 2.8，glowsoft |
| 高光 | `#FFF6D4`，stroke-width 0.9，向下偏移 1.7px |
| 断口 | 5 道短纤维，向外散开 |

**张力即外观：**

| 张力 | 颜色 | 线宽 | 抖动 |
|---|---|---|---|
| < 60% | 暗金 `#BE8922` | 3.2 | 无 |
| 60–85% | 亮金 `#EDC155` | 2.8 | 轻微正弦 |
| 85–95% | 亮金泛白 | 2.2 | 剧烈抖动 |
| ≥ 95% | `#FFF6D4` | 1.6 | 连续高频 |
| 超限 | — | — | 断裂，5 道纤维散开 |

**线越紧越细越亮。** 这符合直觉（拉紧的弦更细），也符合机制（张力越高越危险）。

### 5.3 无相

- **颜色**：`#0B0B08`，比一切其他元素都深
- **做法**：一组重叠圆 → `goo` 滤镜（高斯模糊 16 + 阈值 + 低频位移 scale 7）
- **位移必须小**。scale 超过 15 会把墨体炸成海星状，完全失去"有重量的生物"的感觉
- **壳板接缝**：2–3 道弧线，opacity 0.20，画在滤镜**之外**（保持锐利）
- **不要画闭合的几何多边形**。闭合六边形看起来像齿轮，不像甲壳
- **核心（弱点）**：一个 r=12 的暖色点（`#8A7748` @ 20%），**偏离几何中心**，避免读成靶心

**溅墨**：用独立的 `goo2` 滤镜（模糊 4.5，位移 scale 6），且必须**明显脱离本体**（距离 > 60px）。贴在一起的溅墨会融化进本体，让轮廓变成锯齿。

### 5.4 环境物体

每一个可交互物体都需要**一眼可辨的视觉标签**：

| 物体 | 视觉标签 |
|---|---|
| 石块 | 多边形，有明暗三面，干笔质感 |
| 陶罐 | 圆润，薄 |
| 铁链 | 环环相扣的椭圆，暗色 |
| 竹 | 细长，有节，可弯 |
| 钟 / 鼓 | 大而圆，边缘有金属高光 |
| 梁柱 | 粗，有木纹飞白 |

**所有可被丝线连接的物体，在被瞄准时加一层极淡的金色描边**（opacity 0.25）。这是唯一的交互提示，不加图标。

## 6. 弹道与预判（可读性的技术保障）

画面里有**两条**轨迹，视觉上必须能区分：

| | 已飞过的部分 | 尚未飞过的预判部分 |
|---|---|---|
| 颜色 | 淡墨 `#2A2822` | 金色 `#E8B33C` / `#FFEDB8` |
| 线型 | 虚线 `1 12`，opacity 0.19 | 点线 `1 20`，opacity 0.95 |
| 含义 | 事实 | 预测 |

外加**落点预判**：目标位置一个 `r=26` 的金色圆环 + 一个 `r=42` 的淡环。

**伤害预读标签**：贴在飞行物旁边，一条细引线连出，白底墨字显示"冲击 24 / 对墨甲·有效"。

> 这条预判线是整个游戏**可学习性**的物理载体。没有它，物理就是混沌，玩家无法规划，也就无所谓精通。有了它，玩家能验证自己对 `mv` 和 `v²` 的理解是否正确。

## 7. HUD

**原则上，HUD 几乎不存在。**

| 元素 | 位置 | 说明 |
|---|---|---|
| 丝（4 枚圆点） | 左上 | 已用的填充金色带辉光；未用的空心金环 @ 40% |
| 张力条 | 左下 | 230px 横条，金色填充；95% 处有一道红色"濒断"刻度 |
| 伤害预读 | 跟随物体 | 见 §6 |
| 命名 | 右上 | 毛笔大字 + 金色细线 + 小字注解 |
| 章名 | 右下 | 极淡，opacity 0.5 |

**没有血条。** 主角受伤用画面表现：墨色从画面边缘向内侵蚀。侵蚀到中心 = 死亡。

**没有伤害数字。** 伤害大小用墨色晕染的**扩散范围**表示。

**全游戏文字总量控制在 500 字以内。** 唯一的例外是「命名」。

## 8. 命名系统（涌现翻译层）

高价值物理事件触发时，右上角出现毛笔字命名：

```
        一石          ← 华文行楷 / 楷体，130px，#1A1813
    ─────────       ← #C08A24，1.8px
   单 次 投 石 击 杀   ← 微软雅黑，18px，字距 8
```

配合 **0.3 秒慢镜 + 墨色晕染扩散 + 古琴一记重按**。

> 这不是成就系统，是必需品。物理沙盒的深度是涌现的，而涌现是不可见的。玩家做出了精彩操作却以为是运气——游戏必须主动告诉他"你刚才做的事情很了不起，它叫这个名字"。

## 9. 动效与相机

| 时刻 | 相机 | 时间 |
|---|---|---|
| 蓄力中 | 以主角为中心，**张力越高视野越广** | 实时 |
| **断丝瞬间** | **0.15 秒完全定格** + 屏幕缩放脉冲 | 0.15s |
| 飞行中 | 跟随物体，加残影 / 速度线；主角留在画面边缘 | 实时 |
| 命中 | 慢镜 + 墨点四溅 + 命名扫入 | 0.3s |

**第 2 条是整个游戏操作爽感的来源。** 它不是慢镜，是完全静止。它把"释放"从松手变成一个**有仪式感的瞬间**。

## 10. 性能预算

| 项 | 预算 | 说明 |
|---|---|---|
| 刚体 | ≤ 40 | 水墨风格天然敌人少 |
| Verlet 绳索 | ≤ 4 根 × 12 段 | |
| 墨体粒子 | ≤ 800 | |
| Draw call | ≤ 60 | |
| 墨体渲染 | 半分辨率 RT + 2 次可分离高斯 + step 阈值 | metaball 的廉价近似 |
| 目标 | 骁龙 6 系稳定 60fps | 微信小游戏主力机型 |

> **水墨风格对 2D 物理游戏是技术上最友好的美术风格。** 大量留白 = 大量透明像素 = 极小的纹理。这是该风格的额外红利。

## 11. 禁止事项

1. ❌ 使用饱和度 > 15% 的非金色
2. ❌ 使用纯黑（`#000000`）——最深只到 `#0B0B08`
3. ❌ 主角使用纯黑剪影——会和敌人混淆
4. ❌ 用纯白画雾
5. ❌ 用闭合几何多边形画敌人的甲壳
6. ❌ 高斯模糊 > 25px 作用于薄形状
7. ❌ 添加血条、伤害数字、技能图标
8. ❌ 在画面里加任何装饰性花纹
9. ❌ 让灵丝以外的任何元素发光
10. ❌ 在宣传图、图标、商店图中违反以上任何一条
